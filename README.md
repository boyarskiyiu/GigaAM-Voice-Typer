## 🎯 О программе

**GigaAM Voice Typer** — это программа для распознавания русской речи в реальном времени прямо с микрофона. 
Работает локально, без интернета (после загрузки моделей), автоматически вставляет распознанный 
текст в любое активное окно.

**Разработчик:** Боярский Игорь Юрьевич  
**Модель распознавания:** GigaAM-v3-e2e-rnnt  
**Фильтр мата:** Нейросеть `khvatov/ru_toxicity_detector`  
**Коррекция орфографии:** Яндекс.Спеллер

## ✨ Возможности

### 🔊 Распознавание речи
- **GigaAM-v3-e2e-rnnt** — современная русская модель от SberDevices
- Автовставка текста через `Ctrl+V` в любое активное окно
- Работа в реальном времени (VAD — детектор речи)
- Автовозобновление после паузы
- Поддержка GPU (CUDA) и CPU

### 🛡️ Фильтр нецензурной лексики
- Нейросеть `khvatov/ru_toxicity_detector` (F1 ≈ 0.97)
- Удаление **только токсичных слов**, а не целых предложений
- Защита от ложных срабатываний (список `SAFE_WORDS`)
- Порог чувствительности: **0.9** (удаляет только явный мат)

### 📝 Коррекция и обработка текста
- Автоматическое исправление орфографии через **Яндекс.Спеллер**
- Удаление слов-паразитов («э-э», «м-м», «ага», «угу» и др.)
- Нормализация пунктуации
- Сохранение пользовательских исправлений

### 📂 Работа с аудиофайлами
- Поддержка **WAV, MP3, OGG, FLAC, M4A, AAC, WMA** (через ffmpeg)
- Автоматическая разбивка длинных файлов на куски по 20 сек
- Диалог сохранения результата — рядом с исходным файлом

### 💾 Сохранение сессий
- Каждое распознавание сохраняется в отдельный файл
- Папка `sessions/`, имя файла: `live_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.txt`

### 🎮 Управление
| Клавиша | Действие |
|---------|----------|
| **F2** | Пауза / Возобновить |
| **F3** | Исправить последнюю фразу |
| **F4** | Свернуть окно |

### 🔧 Установка и обновление
- Автоматическая установка недостающих библиотек
- Автозагрузка моделей с зеркала `hf-mirror.com` (доступно в РФ)
- Проверка обновлений программы
- Полное логирование в `gigaam_log.txt`
